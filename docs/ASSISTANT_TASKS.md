## 5. 流式输出体验问题记录

问题名称：流式输出体验不稳定，部分回答仍可能大段输出。

问题表现：

- 固定话术虽然走 `delta`，但因为没有节流，可能被快速塞入队列并一次性输出。
- 上游 LLM 即使 `stream=true`，也可能返回较大的 delta。
- 后端目前没有对 delta 统一做二次切分和节流。
- 部分业务分支仍是内部完整生成后，再由外层输出。
- 前端不是主要问题，主要问题在后端 delta 产生节奏、queue drain 逻辑或上游代理缓冲。

当前处理结论：

- 暂不在当前阶段继续修复。
- 解决方案待定。
- 风险等级：中。
- 影响范围：用户体验。
- 是否影响主流程正确性：暂未发现。
- 是否阻塞下一阶段：不阻塞。
- 是否立即修复：否，进入待办问题池。

后续可考虑：

1. 在 `main.py` 输出包装层统一做 delta 二次切分。
2. 增加轻微节流。
3. 增加 no-buffering headers。
4. 逐步补齐 `push_preview`、`warning_handle`、`warning_trend`、`teacher_risk`、`classroom_health`、`device_ops` 等分支内部 streaming。
5. 增加 streaming smoke 测试。
