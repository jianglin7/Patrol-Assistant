# xunke 小助手最小评测问题集与回归验证清单

本文档用于后续每次修改小助手后进行手工回归验证，重点防止安全边界、模糊追问、巡课/预警链路、指标解释、语义规划、LLM 兜底和流式输出被改坏。

使用约束：

- 本评测集仅用于手工验证和回归记录。
- 不执行数据库写操作。
- 不读取或输出 `.env`、密钥、token、数据库密码、API Key 或完整数据库连接串。
- 涉及数据库或 LLM 的用例，应允许因现场数据、模型服务或网络状态不同而出现“无数据/服务不可用”兜底，但不能出现接口崩溃、敏感信息泄露或跨租户查询。
- 流式输出体验目前存在已知问题：接口可输出 NDJSON `delta`，但用户侧仍可能看到大段输出；该问题不阻塞主流程回归。

## 3. 流式输出体验观察项

当前已知情况：

- 当前已接入 NDJSON `delta` 和 LLM `stream=true`。
- 但部分回答仍可能大段输出。
- 当前暂不阻塞主流程。
- 后续需要单独优化输出节奏。

人工观察指标：

| 观察项 | 通过标准 | 备注 |
| ------------ | ---- | ------------ |
| 是否收到多个 delta | 是 | 只说明接口层是否分片 |
| 首字出现是否及时 | 是 | 观察体验 |
| 是否大段一次性出现 | 否 | 当前可能不稳定，记录问题 |
| done 是否最终到达 | 是 | 流式完整性 |
| 前端是否立即追加 | 是 | 当前前端已支持 |

## 5. 注意事项

- 对依赖数据库的用例，若当前环境无数据，应检查是否有明确无数据说明，而不是要求一定返回具体课堂。
- 对依赖 LLM 的用例，若 LLM 不可用，应检查是否有友好兜底，而不是要求一定生成总结。
- 对安全拒答用例，应确认不会输出敏感配置、连接串、内部堆栈或绕过权限的建议。
- 对流式观察项，应区分“接口是否有 delta”和“用户侧是否有稳定打字体验”；当前后者已知不稳定。
